Which categories do customers buy together?

Dark store shelf planning · Category correlation matrix

How to read this

For each customer we added up how much they spent in each category. Then we checked, category by category, whether customers who spend more on one also spend more on the other (Pearson correlation). Values run from −1 to +1: green means bought together, orange means one tends to replace the other, and near 0 means no link.

      Method and assumptions
      • Spend = quantity × unit price, summed per customer per category ( customers, order lines).
      • Pearson correlation between each pair of category columns across all customers. A customer with no spend in a category counts as $0.
      • Rows that look like repeated lines in the same order are kept, because nothing in the data marks them as errors.
      • Business order follows the letter prefix in the data (A.Milk to J.Chocolates); the prefix is hidden in labels.
      • Customer names are not used and are not included in this page.
